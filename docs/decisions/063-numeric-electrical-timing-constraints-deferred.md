# FVD-0063: Numeric electrical/timing constraints deferred

## Status

Accepted in Phase 7.

## Decision

Voltage, current, thermal, memory, CPU, deadlines, bandwidth, torque, travel,
power, PWM frequency values remain outside; the architecture leaves room for
set-level constraints but establishes nothing about them.
